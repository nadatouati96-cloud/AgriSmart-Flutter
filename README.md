# 🌱 AgriSmart – Smart Agriculture Mobile Application

AgriSmart is a Flutter-based mobile application designed to support smart agriculture by monitoring soil moisture levels and providing useful information about agricultural zones.

The application aims to simplify agricultural monitoring through a clean and user-friendly interface.

## ✨ Features

- **Agricultural Zones:** View and manage information about different agricultural zones.
- **Soil Moisture Monitoring:** Display soil moisture levels for each zone.
- **Zone Details:** View detailed information about individual agricultural zones.
- **Statistics:** Explore agricultural data through a statistics interface.
- **User Profile:** Access profile information.
- **Light and Dark Themes:** Switch between light and dark display modes.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code

### Installation

1. Clone the repository:

```bash
git clone https://github.com/nadatouati96-cloud/AgriSmart-Flutter.git
```

2. Open the project folder:

```bash
cd AgriSmart-Flutter
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```

## 📌 Project Notes

AgriSmart is an academic project developed as part of Flutter cross-platform development coursework. The current version demonstrates the application's interface and agricultural monitoring features using sample data.
